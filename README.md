# Sandėlio komplektavimas – Android APK

Šioje saugykloje laikomas Android projekto ZIP ir automatinio APK kūrimo scenarijus.

Kiekvienas sėkmingas GitHub Actions paleidimas sukuria debug APK artefaktą. Atidaryk **Actions → Build Android APK → naujausią sėkmingą paleidimą → Artifacts** ir atsisiųsk APK ZIP.

Programėlė skirta veikti telefone be interneto ir serverio. Interneto reikia tik APK kompiliavimo metu, kad būtų atsisiųstos Android kūrimo priklausomybės.
